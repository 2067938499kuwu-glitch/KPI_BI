# KPI_BI 演示数据流转说明

## 定位

当前版本为可操作演示环境。演示数据允许预置和新增，但页面展示、工作台任务与经营指标必须从同一业务记录派生。浏览器使用 `localStorage` 保存演示操作；测试环境使用隔离的内存快照。

正式环境接入时保留页面与 `demoSelectors.js` 中的口径函数，只将 `DemoDataProvider` 的读取、保存动作替换为服务端 API/数据仓库适配器。

## 数据入口与流向

| 业务域 | 数据入口 | 主数据/业务记录 | 下游使用 |
| --- | --- | --- | --- |
| 招聘 | 新增岗位、上传候选人、候选人流程处理、招聘日报、SSC 同步 | 岗位、候选人、岗位应聘记录、招聘日报、SSC 人员编号 | 工作台招聘待办、招聘漏斗、正式入职、岗位缺口、流程差异 |
| 选题 | 新建选题、审核、退回、选为项目 | 选题、版本、审核状态、唯一项目编号 | 工作台选题待办、通过率、退回数、转项目数 |
| 项目 | 选题立项、独立新建、环节进度更新、内部短剧成本录入 | 项目台账、来源选题、制作环节、风险标签、预算成本、人力成本、算力成本、投流成本、真实成本 | 工作台延期任务、进行中项目、延期项目、平均进度、真实成本及成本构成 |
| 绩效 | 目标下发、评分、复审、审批、申诉 | 绩效考核单、结果版本、操作日志 | 绩效完成率、平均得分、人员看板 |
| 周报 | 周报页面提交与版本留痕 | 周报记录、提交状态、周期 | 人员看板、绩效证据（不直接改分） |
| SSC | SSC 数据维护页面、招聘到岗同步 | 人员花名册、到岗状态、人员编号 | 招聘到岗状态、正式入职依据 |

## 核心统计口径

- 招聘漏斗：仅纳入“已提交且工作截图数量大于 0”的招聘日报；草稿、退回和缺图记录排除。
- 正式入职：岗位应聘记录处于“实习期/已转正”，并保留 SSC 人员编号关联。
- 选题转化率：已生成唯一项目编号的选题数 ÷ 审核通过选题数。
- 进行中项目：项目台账基础状态为“进行中”的项目数。
- 延期项目：项目风险标签包含“延期”的去重项目数。
- 人员逾期任务：来源业务记录已过截止时间且业务状态尚未关闭的任务数。

驾驶舱指标卡可点击查看公式、来源表、纳入/排除记录数、更新时间和口径版本。

## 工作台闭环

工作台不保存独立任务副本。`selectWorkbenchTasks` 根据招聘应聘状态、选题审核状态和项目风险状态生成待办。处理任务时通过来源编号回写业务记录；来源状态变化后，工作台任务和驾驶舱统计同步重算。

## 演示与正式环境切换

演示环境：

1. 初始快照生成招聘、选题、项目和运营数据。
2. 页面操作写入统一仓库并持久化到浏览器。
3. “系统配置”中的“重置演示数据”恢复初始快照。

正式环境：

1. 将初始快照读取替换为业务 API 查询。
2. 将集合更新函数替换为带业务编号、版本号和幂等键的写接口。
3. 服务端返回原始业务记录，前端继续通过相同选择器计算展示指标；生产数据仓库可用同一公式做对账。
4. 权限范围必须在服务端过滤，前端角色控制只作为交互层补充。
