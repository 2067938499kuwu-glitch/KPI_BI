# 项目与内容编码规范

## 1. 适用范围

本规范适用于选题审核通过后的项目立项，以及项目下多集剧本、视频和内容版本的编号管理。项目可以采用内部制作或外部制作，编码规则保持一致。

## 2. 编码格式

| 对象 | 格式 | 示例 | 含义 |
| --- | --- | --- | --- |
| 项目总编号 | `PRJ-YYYYMMDD-NNNN` | `PRJ-20260717-0001` | 2026 年 7 月 17 日创建的第 1 个项目 |
| 剧本主编号 | `{项目总编号}-SC-NNNN` | `PRJ-20260717-0001-SC-0003` | 该项目第 3 集剧本 |
| 视频主编号 | `{项目总编号}-VD-NNNN` | `PRJ-20260717-0001-VD-0008` | 该项目第 8 集视频 |
| 剧本版本编号 | `{剧本主编号}-VNN` | `PRJ-20260717-0001-SC-0003-V02` | 第 3 集剧本的第 2 个版本 |
| 视频版本编号 | `{视频主编号}-VNN` | `PRJ-20260717-0001-VD-0008-V03` | 第 8 集视频的第 3 个版本 |

字段说明：

- `PRJ`：项目固定前缀。
- `YYYYMMDD`：项目正式立项并生成编号的年月日。
- 项目 `NNNN`：同一立项日期内的四位流水号，从 `0001` 开始。
- `SC`：剧本（Script）固定前缀。
- `VD`：视频（Video）固定前缀。
- 内容 `NNNN`：同一项目、同一内容类型下的四位独立流水号，从 `0001` 开始。
- `VNN`：版本号，从 `V01` 开始；修改内容时依次递增为 `V02`、`V03`。

## 3. 核心关系

```text
项目 PRJ-20260717-0001
├─ 剧本 SC-0001、SC-0002、SC-0003……
└─ 视频 VD-0001、VD-0002、VD-0003……
```

- 剧本只关联项目，视频也只关联项目。
- 剧本与视频之间不建立强制的一对一、一对多或集号对应关系。
- 剧本和视频的集数可以不同，新增顺序和当前版本也可以不同。

## 4. 生成与变更规则

1. 选题“审核通过”不生成项目编号；点击“选为项目”并成功立项后才生成项目总编号。
2. 项目总编号生成后永久不变，不因项目名称、负责人、制作方式、状态或日期调整而改变。
3. 立项时分别填写剧本集数和视频集数，系统按两个独立流水批量生成主编号。
4. 后续新增剧本或视频时，只取对应内容类型当前最大流水号加一；已删除或作废的编号不重复使用。
5. 内容修改不重新生成主编号，只生成新的版本编号。主编号 `...-SC-0001` 或 `...-VD-0001` 保持不变。
6. 版本从 `V01` 开始递增，旧版本保留并标记为历史版本，最新版本标记为当前版本。
7. 项目日流水、剧本流水、视频流水都应由服务端或数据库保证唯一，禁止由多个客户端自行计算后直接写入生产数据。

## 5. 建议数据字段

### 项目

| 字段 | 用途 |
| --- | --- |
| `id` | 系统内部技术主键，不对业务人员展示 |
| `projectCode` | 不可变项目业务编号，唯一索引 |
| `establishedAt` | 正式立项时间，也是项目编号日期来源 |
| `topicId` | 来源选题技术主键 |

### 剧本或视频

| 字段 | 用途 |
| --- | --- |
| `id` | 内容技术主键 |
| `projectId` | 所属项目技术主键 |
| `code` | 不可变内容主编号，唯一索引 |
| `episodeNo` | 当前内容类型下的流水序号 |
| `currentVersion` | 当前版本数字 |
| `versionCode` | 当前完整版本编号 |
| `status` | 未开始、进行中、已完成、已作废等 |

内容版本记录应另外保存 `contentId`、`version`、`versionCode`、文件或正文、创建人、创建时间和变更说明，并对 `(contentId, version)` 建立唯一约束。

## 6. 页面应用

- 选题立项：展示编码规则，并分别录入剧本集数、视频集数。
- 项目台账：项目名称下展示项目总编号，不展示技术主键。
- 项目详情：并列展示“剧本编码”和“视频编码”两个独立台账。
- 内容操作：支持分别新增剧本、新增视频和生成新版本。
- 版本反馈：生成新版本后，主编号不变，只将版本后缀从 `V01` 递增。

## 7. 验收示例

项目 `PRJ-20260717-0001` 在立项时填写 2 集剧本、3 集视频，应生成：

```text
剧本：PRJ-20260717-0001-SC-0001
      PRJ-20260717-0001-SC-0002

视频：PRJ-20260717-0001-VD-0001
      PRJ-20260717-0001-VD-0002
      PRJ-20260717-0001-VD-0003
```

当第一集剧本修改一次后：

```text
剧本主编号：PRJ-20260717-0001-SC-0001（不变）
当前版本号：PRJ-20260717-0001-SC-0001-V02
```
